# AITS Campus Events API

A backend API for managing college events, administrator access, and student event registrations at AITS.

# Technologies Used

* Python
* FastAPI
* MySQL
* SQLAlchemy
* JWT Authentication

# Features

* Create and manage college events
* Administrator authentication and authorization
* View events and student registration details
* Register students for events
* Store event and registration data in MySQL
